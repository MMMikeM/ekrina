# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers choosing a fuzzy-search library for a search-as-you-type interface, such as a command palette or a picker; backend one-shot lookups are a secondary workload.
LLM agents that recommend a library to those developers, reading the Markdown copy of each page and `llms.txt`.

## Product Purpose

The documentation site for `ekrina`, a zero-dependency fuzzy matcher published on npm.
It explains the API and shows, from measured evidence, how Ekrina compares with seven other libraries on match quality, junk results and speed, so a reader can decide which to use.

## Positioning

Ekrina reports how each match was made (a tier, highlight ranges and a score pinned by tests) and corrects up to two typos, and its benchmark is published with the method, the frozen corpora and every cell in `bench/results.json`.
Every number on the site is generated by `pnpm bench`.

## Operating Context

Pages are copied from README.md and docs/ at build time, and the API reference is generated from the source's JSDoc, so the site holds no prose that can drift from the repository.
Every page is also served as Markdown, and every chart has a table twin in the HTML so crawlers and agents get the numbers without running scripts.
The site deploys only when a stable release is published.

## Capabilities and Constraints

Static Astro Starlight site, rendered at build time; interactive controls work without JavaScript where possible.
Timings exist for the en and native corpora at 10k and 100k items; the emoji corpus is scored for quality only.

## Evidence on Hand

`bench/results.json`: per library, headline and per-family MRR, junk rates, the 24 timed queries' per-query times, cold first answers, build times, memory and gzip size.
No testimonials, users or adoption figures exist, and none may be invented.

## Product Principles

- Every published number traces to `bench/results.json`.
- Ekrina's losses are shown as plainly as its wins, with the same visual weight.
- Speed is shown beside the quality that comes with it, at the list size the reader has.
- What a chart shows, a table on the same page also states, for readers and agents who cannot see it.
